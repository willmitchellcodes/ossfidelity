Open weights aren't the whole story

The Open Source AI Definition asks for three things: the weights, the code, and enough about the training data to rebuild the model. Most "open" models share only the first.

A small test anyone can rerun

We only score tasks a script can check, because AI is most useful where its output can be verified. Every model runs the same {{ site.data.bench.tasks_version | default: "1.0" }} question set on GitHub's free machines (4 CPU cores, 16 GB, no graphics card), so speed reflects an ordinary laptop. All questions use invented facts, so no model can have memorized them, and every prompt and answer is published.
