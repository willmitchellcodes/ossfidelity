    What we never score

    Stars. In July 2024, 16.66% of popular GitHub repositories had fake-star campaigns (He et al., ICSE 2026). Popularity is easy to buy and tells you little about whether software is well kept.

    The host, mixed into the project. Where code lives matters (for example, whether the host trains AI on it), so we show it separately. It's not the project's fault.

    AI use, either way. We show how many recent commits disclose AI help, but there isn't enough evidence yet to say whether that makes a project better or worse.
